# NCAtoys

Experimental neural-net-based cellular automata project.

The rules for the cellular automata here are not derived from a conventional lookup table or math function, but instead from a neural net which takes in a cell's value and its surroundings, and outputs its value for the next step.

Nets can be randomly initialized, or trained on patterns and images.

## Running

Execute all cells in order inside `run.ipynb`.

> You might need to adjust the run device and/or change the settings to fit your computer.
